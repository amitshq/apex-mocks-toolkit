# Contributions Welcome

If you'd like to submit a contribution to this testing comparison and toolkit, please do! Contributions that enhance the testing methodology (to further verify or challenge the given results) or extend the CRUD mocking toolkit with new, related concepts are both welcome.

PRs that do so are welcome! When submitting a pull request, please do two things:

- update the README.md with the output of your results, or a description of what your addition does
- add your tests in a new Apex class file with your name and "_Tests.cls" - e.g. a file named "yourname_Tests.cls" and its associated metadata file.
